# 📝 Todo-List

Uma aplicação web simples, moderna e funcional para gerenciamento de tarefas (To-Do List). Desenvolvida com HTML, CSS e JavaScript puro (Vanilla JS), com foco em boas práticas de manipulação de DOM e uma interface agradável.

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Insira novas tarefas de forma rápida e intuitiva.
- **Editar Tarefas:** Abra um popup (modal) para atualizar o texto de uma tarefa existente.
- **Excluir Tarefas:** Remova tarefas que não são mais necessárias.
- **IDs Únicos:** Cada tarefa recebe um ID único gerado dinamicamente, garantindo a integridade das ações de edição e exclusão.
- **Design Responsivo:** Interface adaptável para telas menores.
- **Animações e Feedback Visual:** Efeitos de hover, transições suaves e animação de entrada para novas tarefas.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização moderna com uso de Variáveis CSS (`:root`), Flexbox para alinhamento, animações (`@keyframes`) e design responsivo.
- **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM, criação dinâmica de elementos e delegação de eventos (Event Delegation).
